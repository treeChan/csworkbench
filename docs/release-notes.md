# v0.4.5-preview.809121 Release Notes

> 🔭 这是 **预览版**（preview）：给加入预览计划的用户提前体验新功能，测试稳定后转为正式版。
> 想先体验可到 设置 → 关于 → 勾选「加入预览计划」；随时可退出。
>
> 本版本自 v0.4.4 以来的改动见下方各节。

## ⚠️ 本次修复（自 v0.4.5-preview.809011）

- **修复更新弹窗导致软件无法使用的严重问题**：更新弹窗遮罩的样式用了
  `display: flex`，把 HTML 的 `hidden` 属性压掉了，导致——
  - 弹窗从软件一启动就常驻屏幕，此时更新信息还没到，**内容是空白的**，全屏遮罩挡住所有页面；
  - 点「稍后」**关不掉**；
  - 空白弹窗期点「立即更新」会提示「没有待安装的更新」。
- 现已修复：弹窗**只在确实检测到新版本时才弹出**，点「稍后」正常关闭；
  「立即更新」增加兜底——即使极端时序下也能现场重新检查一次再安装，不再出现
  「提示有更新却装不上」。
- **更新说明完整展示**：不再截断（去掉了 600 字上限），并支持 Markdown 排版
  （标题 / 列表 / 加粗 / 代码块 / 链接等正常显示），说明过长时在弹窗内滚动查看。

## 存储位置统一 📂

- **设置页只保留一个「数据文件夹」**：数据库自动保存在该文件夹下 `workbench.db`，
  上传文件自动保存在其下 `artifacts` 子目录，不再需要分别配置两个路径。
- **老版本自动迁移**：若之前的数据库与上传目录分开放置，首次启动会自动把上传文件
  迁移到数据库所在文件夹下（迁移全程校验、失败自动回滚，数据不丢失）。该兼容迁移
  会在后续几个版本中持续保留。
- 数据库大小说明：数据库本身存的是文本 / 数值记录，个人使用量级通常只有几 MB；
  权重 / 图片等大文件本来就放在 `artifacts` 目录。

## 数据库向前兼容 ✅

- 思维导图新增的 3 张表（`mindmaps` / `mindmap_nodes` / `mindmap_edges`）与 2 列
  （`font_size` / `font_family`）由启动时的幂等迁移自动落库，老数据无损升级。
- 新增维护文档 `docs/database-schema.md`，记录表结构、迁移策略与前后向兼容保证。

## 更新渠道（桌面版）📡

- 设置页新增**「加入预览计划」开关**：默认关闭（只接收正式版更新）；开启后同时
  接收预览版与正式版更新，提前体验新功能。随时可退出，退出后回到正式版渠道。
- 预览计划状态**持久保存**，重启应用仍保持，直到手动退出。
- 预览版带完整版本号（如 `v0.4.5-preview.809121`），不会混淆；预览测试稳定后转为
  正式版发布，无需改任何代码。
- 未加入预览计划的用户不会收到预览版推送（正式渠道自动排除 pre-release）；
  GitHub Releases 页面仍可手动下载任意版本的安装包。

## 开发者署名 ✍️

- 设置页「关于」新增**开发者**信息，底部状态栏同步显示版权署名
  （© 2026 treeChan & JesseFather）。

## 亮暗模式体验修复 🌗

- **设置页**选择亮暗模式为**持久化配置**，点击立即生效，之后打开应用保持。
- **顶栏快捷按钮**改为**会话内快速切换**：一键在亮 / 暗间切换，刷新页面保持本次
  会话的选择；但不改动设置页的持久化配置记录，关闭应用后恢复设置页的选择。
- 顶栏按钮现在直接展示**当前亮暗模式**（🌙 暗色 / ☀️ 亮色），不再容易误判。

## 版本号单一源 🔢

- 新增仓库根 **`VERSION` 文件**作为版本号唯一来源，以后只改这一处。
- `app/config.py` 运行时直接读它；`tauri.conf.json` 不再写版本号（自动回退 Cargo.toml）；
  `Cargo.toml` / `package.json` 由 `scripts/sync_version.py` 自动同步，构建前自动执行。
- 改版本号 = 改 `VERSION` 一行（或 `python scripts/sync_version.py 0.4.5`），其余全部跟随，
  不再有 4 个文件手工同步、漏改导致版本不一致的问题。
- 新增 [docs/versioning.md](versioning.md) 版本号规范：主/次/修订号定义、预览版
  `x.y.z-preview.MDHHNN` 命名、正式版 `v*` tag 与预览版固定 `preview` tag 的发布流程。

## 页面标题统一 🎨

- 主页 4 个选项卡（今日 / 项目 / 周复盘 / 设置）标题样式统一为
  **图标 + 标题 + 小字**：今日页显示日期、项目页显示「共 N 个项目」、
  周复盘页显示「共 N 篇」、设置页不显示统计小字。
- 移除周复盘列表页顶部多余的面包屑导航（点进具体条目后才显示，
  与项目页保持一致）。

## 统一更新体验 🔔

- **全局更新弹窗**：检测到新版本时在**任意页面屏幕正中**弹出统一风格的弹窗
  （替换原来的 Windows 原生对话框），展示版本号 + 完整更新日志（Markdown 排版），
  点「立即更新」下载安装重启、点「稍后」关闭。亮暗主题下都美观一致。
- **启动自动检查**：启动后后台静默检查更新；有新版 → 自动弹窗，已是最新 → 不打扰，
  网络不通 → 静默、每分钟重试直到拿到结果。
- **更新进度条**：弹窗内实时展示下载进度与已下载/总大小。
