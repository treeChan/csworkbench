# v0.4.5-preview.8101351 Release Notes

> 🔭 这是 **预览版**（preview）：给加入预览计划的用户提前体验新功能，测试稳定后转为正式版。
> 想先体验可到 设置 → 关于 → 勾选「加入预览计划」；随时可退出。
>
> 本版本是 v0.4.5-preview.809181 的增量更新，改动见下方各节。

## 更新下载体验大幅改进 🔧

- **修复下载进度条不动的严重问题**：此前进度条永远显示 0.0 MB——原因是
  tauri 更新插件上报的「进度」其实是单次网络包的大小（几 KB），不是累计下载量。
  现已改为在桌面端累计真实已下载字节，进度百分比、已下载 / 总大小实时准确。
- **下载信息更完整**：进度条下方同时展示**下载速度**（KB/s 或 MB/s）与
  **预计剩余时间**，下载过程一目了然。
- **下载中可以取消**：点「立即更新」开始下载后，「稍后」消失、「立即更新」
  变为只读的下载状态（不再是个可点的按钮），并出现「取消」按钮——下载没完成时
  可随时反悔，点「取消」**真正中断下载**（停止占用带宽），不会安装任何东西；
  想装再点「立即更新」重新下载即可。
- **下载中关闭应用是安全的**：安装包只在下载完成后才写入系统，下载过程中
  直接关掉应用不会留下半成品或损坏文件（网络连接自动中断，无残留）。

## 设置新增「自动检查更新」开关 ⚙️

- 设置 → 关于 → 新增**「自动检查更新」开关**（默认开启）：开启时打开软件自动
  扫描更新仓库，有新版本弹窗提示；关闭后**打开软件不再主动扫描更新仓库**，
  想检查时点「检查更新」按钮即可。手动检查不受该开关影响。
- 关闭状态下即使网络恢复也不会自动弹更新提示，直到手动检查或重新开启。

## 开关样式升级 🎨

- 设置页的「加入预览计划」「自动检查更新」从普通复选框换成**胶囊开关**
  （iOS 风格滑钮），亮 / 暗主题下都更美观、点击区域更大。

## 其他修复 🛠️

- 修复样式表里一个多余大括号导致部分样式规则失效的历史遗留问题。
