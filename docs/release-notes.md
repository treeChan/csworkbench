# v0.4.5-preview.8111008 Release Notes

> 🔭 这是 **预览版**（preview）：给加入预览计划的用户提前体验新功能，测试稳定后转为正式版。
> 想先体验可到 设置 → 关于 → 勾选「加入预览计划」；随时可退出。
>
> 本版本是 v0.4.5-preview.8102246 的增量修复。

## 本次修复 🔧

- **修复无更新时底栏常驻「正在下载更新」**：上一版本状态栏下载条在没有进行更新、
  甚至没有新版本时也一直显示在底栏，点击还会打开一个虚假的「准备下载」弹窗。
  原因是下载条样式覆盖了 HTML 的隐藏属性。现已修复：无下载任务时底栏不再显示下载条，
  仅当真正下载更新（含最小化后）才会出现。

## 更新体验优化 ⚙️（8102246 引入，本版下载时即可实测）

> 说明：上一版本的更新弹窗优化需在「更新过程」中才能看到。本次从 8102246 升级到本版本
> 的下载过程，将第一次实际使用新弹窗——正好一并验证：

- **修复取消后需跳页才正常的 Bug**：点「检查更新 → 立即更新 → 取消」后即可直接再查，
  并会弹「更新已取消」提示。
- **断网不再无限等待**：下载更新时若网络中断（连续 30 秒无进展），自动停止并提示
  「网络连接已中断」，检查网络后点「重试」继续，不再卡死。
- **更新弹窗可最小化**：下载中在「取消」旁新增「最小化」按钮，可收起弹窗到底部状态栏，
  状态栏实时显示下载进度（百分比 / 速度 / 剩余时间），点击状态栏即可恢复弹窗。
  下载完成自动弹出「正在安装并重启」；下载失败时状态栏变红并弹提示。
- **提示勿关闭软件**：下载中会提示「下载时请不要关闭软件，否则更新会中断」。

## 思维导图新能力 🗂️

- **容器节点**：新增「容器」节点类型（圆角虚线框 + 半透明紫底 + 角标），拖动普通节点
  落入容器矩形即可自动绑定，容器拖动时子节点跟随；工具栏新增 [容器] / [入容器] /
  [移出] 按钮，支持不嵌套、不跨图等校验。
- **笔记 Markdown 渲染**：实验详情 / 结果页的笔记支持 Markdown 与纯文本两种格式切换。
- **搜索高亮**：全局搜索命中关键词时展示上下文并高亮匹配位置（紫色 <mark>）。

## 思维导图连线重做 🔗

- 连线改为**纯锚点拖拽**（Figma 风格）：去掉了连线模式按钮，选中节点即显示锚点、
  从锚点拖拽即可连线；修复上下方向连边失败，连线端点自动吸附最近一侧。
- 删除节点时自动清理孤儿连线。
- 支持节点**填色 / 字色自定义**，并修复 PNG 导出过黑问题。
