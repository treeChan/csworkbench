# v0.4.4 Release Notes

## 存储位置统一 📂

- **设置页只保留一个「数据文件夹」**：数据库自动保存在该文件夹下 `workbench.db`，
  上传文件自动保存在其下 `artifacts` 子目录，不再需要分别配置两个路径。
- **老版本自动迁移**：若之前的数据库与上传目录分开放置，首次启动会自动把上传文件
  迁移到数据库所在文件夹下（迁移全程校验、失败自动回滚，数据不丢失）。该兼容迁移
  会在后续几个版本中持续保留。
- 数据库大小说明：数据库本身存的是文本 / 数值记录，个人使用量级通常只有几 MB；
  权重 / 图片等大文件本来就放在 `artifacts` 目录。

## 数据库向前兼容 ✅

- 思维导图新增的 3 张表（`mindmaps` / `mindmap_nodes` / `mindmap_edges`）与 2 列
  （`font_size` / `font_family`）由启动时的幂等迁移自动落库，老数据无损升级。
- 新增维护文档 `docs/database-schema.md`，记录表结构、迁移策略与前后向兼容保证。

## 更新渠道（桌面版）📡

- 设置页新增**「加入预览计划」开关**：默认关闭（只接收正式版更新）；开启后同时
  接收预览版与正式版更新，提前体验新功能。随时可退出，退出后回到正式版渠道。
- 预览计划状态**持久保存**，重启应用仍保持，直到手动退出。
- 预览版带完整版本号（如 `v0.4.4-preview.1`），不会混淆；预览测试稳定后转为正式版
  发布，无需改任何代码。
- 未加入预览计划的用户不会收到预览版推送（正式渠道自动排除 pre-release）；
  GitHub Releases 页面仍可手动下载任意版本的安装包。

## 开发者署名 ✍️

- 设置页「关于」新增**开发者**信息，底部状态栏同步显示版权署名
  （© 2026 treeChan & JesseFather）。

## 亮暗模式体验修复 🌗

- **设置页**选择亮暗模式为**持久化配置**，点击立即生效，之后打开应用保持。
- **顶栏快捷按钮**改为**会话内快速切换**：一键在亮 / 暗间切换，刷新页面保持本次
  会话的选择；但不改动设置页的持久化配置记录，关闭应用后恢复设置页的选择。
- 顶栏按钮现在直接展示**当前亮暗模式**（🌙 暗色 / ☀️ 亮色），不再容易误判。
