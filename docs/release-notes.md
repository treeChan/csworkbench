# v0.4.6-preview.08241522 Release Notes

> 🔭 这是 **预览版**（preview）：给加入预览计划的用户提前体验新功能，测试稳定后转为正式版。
> 想先体验可到 设置 → 关于 → 勾选「加入预览计划」；随时可退出。
>
> 自 **v0.4.6-preview.08241339** 起的增量: 图表数据点改逐条勾选 + 标题可编辑, 指标删除留在上传结果页, 批量粘贴支持 `name: value` 单列格式.

## 指标图表改逐条勾选 + 标题可编辑 📊

之前图表只能按「指标名」整体选, 想剔除一条用不上的数据做不到. 现在:

- **逐条勾选**: 数据点列表展示本实验全部 metric, 每行有 checkbox (点行任意位置也能切换). 默认全选, 想剔除就点掉.
- **批量按钮**: 全选 / 全不选 / 反选, 大量数据时一键搞定.
- **标题输入框**: 顶部新增文本框, 默认填「第一个勾选指标名」, **用户可改**. 清空 → 自动恢复用第一个勾选指标名.
- **多指标自动分组**: 勾了多个不同 key 的 metric, Plotly 自动画多条 trace 并显示图例 (颜色区分).

## 上传结果页指标删除跳转修复 🛠️

之前在「上传结果」页删一条 metric 后会跳回实验详情页, 想连续删几条得来回切. 现在:

- 走专属端点 `POST /experiments/{id}/metrics/{mid}/delete`, 删除后**留在 results 页**.
- 校验 `metric.experiment_id == experiment_id`, 用错的 experiment_id 删会 404 — 防止误删别人的 metric.
- 旧端点 `/metrics/{id}/delete` 保留作 fallback (向后兼容).

## 批量粘贴支持 `name: value` 单列格式 📋

之前批量粘贴对 `key\tvalue\tnote` 三列格式最稳, 但用户经常从日志/屏幕复制这种:

```
平均角误差（Angle）: 6.15°
方向余弦误差（Cosine）: 0.0093
```

这种格式之前会识别成 TSV 但整行算 key、数值 NaN. 现在:

- 新增**单列 key:value 识别** (放在 Markdown 表之后, TSV 之前): 检测到整段无 `\t` 无 `|` 但含 `:` 或 `=` 时, 按行匹配 `name: value` / `name = value`.
- 自动剔除数值里的单位符号 `°` / `%` / `‰`.
- note 字段留空 (这种格式本身不带 context).
- 状态栏会出现「✓ 解析成功 (单列 key:value, ...)」 提示.

## 体验优化 🎨

- 图表区行 hover 浅紫底, key 名紫色等宽, checkbox 整行可点击切换.
- metric 列表最大 220px 高 + 滚动, 多到 50 条也不撑页面.
- 图表类型切换、下载 PNG、Plotly mode bar 保持不变.
