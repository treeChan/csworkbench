# v0.4.6-preview.8121522 Release Notes

> 🔭 这是 **预览版**（preview）：给加入预览计划的用户提前体验新功能，测试稳定后转为正式版。
> 想先体验可到 设置 → 关于 → 勾选「加入预览计划」；随时可退出。
>
> 自 **v0.4.5 正式版** 以来累积的新增功能, 已通过多轮预览迭代稳定, 推荐升级体验.
> 旧数据无需迁移, 升级后直接可用.

## 实验管理小修 ⚙️

- **创建实验时默认选中当前目标**: 在目标详情页点「新建实验」时, 目标下拉框自动
  选中当前目标 (URL `?goal_id=N`), 不用再手选一次. 没有目标时保持未选.

## 文件与成果全面升级 📂

「文件与成果」一栏从原本的扁平缩略图, 升级为可分组的**目录树**展示:

- **目录树渲染**: 按 `original_name` 的 `/` 分段生成嵌套文件夹, 支持任意深度
  (例如 `train/loss_curves/epoch_10.png` 树形展示). 不用客户端 JS 计算, 服务端
  `crud.build_artifact_tree` 直接拼好, 模板只负责渲染 (避免 Jinja 嵌套 for 循环
  的变量作用域 bug).
- **缩略图网格 + 灯箱**: 图片以网格缩略图展示, 点击触发**单例灯箱** (全页遮罩 +
  大图 + 标题 + 上一张 / 下一张 / 关闭按钮, 支持 ← → Esc 键盘导航). 同一 scope
  (如某个实验) 的图片归为一组, 灯箱翻页只在组内进行, 不会跨 scope.
- **`/api/artifacts/{id}/inline` 端点**: 返回图片原 `content-type` 但**不带**
  `Content-Disposition: attachment`, 让 `<img>` 标签可以直接加载, 不会触发下载.
- **新文件树宏 `_macros.html`**: 集中所有共享模板片段 (文件树 + 灯箱), 详情页和
  上传结果页都引用同一份.

## 项目级自定义文件类别 🗂️

「文件与成果」顶层不再固定, 改为**项目级自定义类别**:

- **类别管理**: 项目编辑页新增「文件与成果类别」卡片, 可**增删改**本项目下的
  类别列表 (默认: 示意图 / 数据可视化 / 实验结果 / 模型权重 / 其他). 顺序可调,
  数据存到 `Project.categories_json` (TEXT 字段, JSON 列表).
- **上传时选类别**: 上传表单新增类别下拉, 必填; 服务端校验必须在白名单内, 不在
  返 400.
- **类别下子目录**: 选完类别还能继续填子目录 (如 `示意图/网络结构`), 树形展示
  类别 → 子目录 → 文件.
- **未分类兜底**: 旧文件 (无类别前缀) 或被删除类别的遗留文件, 自动归入「未分类」.

## 文件夹可拖拽 + 可改名 🖱️

- **拖拽改子目录**: 缩略图 / 文件卡片可拖到任意文件夹 (或根级空白处), 拖到目标时
  目标 folder 紫光描边高亮, 松手自动保存. 服务端 `crud.move_artifact` 改
  `original_name`, 磁盘文件 (随机名) 不动.
- **双击子目录改名**: 子目录名双击进入编辑态 (input), Enter 提交, Esc 取消.
  服务端 `crud.rename_folder` 批量改本 project 下所有以旧路径开头的 artifact
  (含旗下 goal / experiment 归属), 支持中英文.
- **API**: `POST /api/artifacts/{id}/move` (folder=新子目录) + `POST /api/folders/rename`
  (project_id + old + new). 路径清洗防 `..` 注入.

## 体验优化 🎨

- 文件树相关 CSS (拖拽光标 / 紫光描边 / 改名 input 紫边 / folder 名 hover 浅紫底)
  与主题色 (紫 #7C3AED) 统一, 暗色模式自适应.
- 缩略图 `loading="lazy"`, 列表很长时首屏更快.
