## 实验详情页图表区 📊

之前实验的指标只能在「指标记录」表格里逐条看, 想对比消融实验只能下载后用 Excel / Python. 现在直接在实验页出图:

- **三种图表切换**: 条形图 / 折线图 / 表格, 点一下切换.
- **横轴 = 指标的「备注」** (`Metric.note`), 比如 `深监督权重0.05` / `深监督权重0.10` / `深监督权重0.20`.
- **纵轴 = 选中的指标** (`Metric.key`), 比如 `方向余弦误差` / `平均角误差`. 顶部下拉框切换.
- **Raw 不聚合**: 同一 (key, note) 组合下所有数据点都画上, 折线图按时间排序 (如果你先记权重0.10 后记0.05, 折线图也按记录时间连).
- **下载 PNG**: 一键把当前图存为图片 (1200×600), 用 Plotly 内置的 `downloadImage` API.
- **主题适配**: 颜色跟着紫色主题 (`--c-primary`), 暗色模式自动反转 plot 背景.

## 批量粘贴录入指标 📋

消融实验一次要记好几条指标 (一个 note 配 2-3 个指标), 之前要刷新页面 N 次. 现在粘贴一段文本就能批量录入:

- **三种格式自动识别** (粘贴后点「解析预览」):
  - **TSV 无表头** (Excel 直接复制粘贴最常见): `loss\t0.5\tepoch 1`
  - **TSV / Markdown 表** (有表头, 自动识别 `key/value/note` 列): 跳过第一行
  - **JSON 数组**: `[{"key":"loss","value":0.5,"note":"epoch 1"}]`
- **字段名兼容**: `key/name/指标/名称` / `value/val/数值/score` / `note/备注/comment/label` 都认.
- **预览区** 显示将录入的 N 条, 任一行数值非数字或名称空 → 红字标错, 「确认导入」按钮禁用.
- **整批校验**: 任一行不合规 → 整批拒绝, 不会有「半成功」的情况.
- **允许重复**: 同 (key, note) 可重复加, timestamp 取当前时间 — 适合「同配置跑多次取每次结果」.

## 项目编辑/删除 UX 改进 ✏️🗑️

之前编辑项目表单偶尔会误建新项目, 删除按钮太显眼容易误点. 本轮收敛:

- **编辑改走更新路由**: 表单 action 按模式路由, 改名不再误建新项目, 重名校验排除自身.
- **删除改侧滑/菜单**: 列表页用侧滑删除 (右侧 › 触发, 左滑露出左侧删除按钮), 详情页删除收进「⋯」菜单.
- **统一二次确认**: 全局危险确认弹窗 (红字 + 删除后果说明), 编辑按钮保留在明面.
- 新增图标: `i-chevron-right` / `i-more-horizontal`.
