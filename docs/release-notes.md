## 思维导图编辑页布局修复 🧠

修了导图画布页的几个布局/功能问题:

- **左侧导航宽度不再漂移**: 进入导图页后左侧导航保持和全局一致的 84px, 不再因内容伸缩.
- **工具栏文字按钮不再截断**: 「入容器 / 移出 / 导出 PNG」等带文字按钮此前被固定宽度压扁, 出现文字重叠、截断、丢失. 现在按钮按内容自适应宽度, 纯图标按钮保持等宽.
- **恢复被误清的全局功能**: 此前导图页把全局脚本整块清空, 导致主题切换、Ctrl+K/Ctrl+N 快捷键、快速创建、数据库健康检测、更新弹窗等全部失效. 现已全部恢复.
- **画布高度修正**: 画布容器改为填满主区网格, 底部不再被裁掉.
- **Ctrl+K 不再抢焦点**: 导图页搜索框隐藏时不聚焦它, 画布快捷键 (Del / Ctrl+Z / Ctrl+Shift+Z) 正常工作.

## 构建流程加固 🛠️

- 修复预览版 CI 在「读取 release notes」步骤偶发失败的问题: release notes 文件缺末尾换行, 导致 heredoc 的 `EOF` 分隔符与内容粘成一行, 解析报 `Matching delimiter not found 'EOF'`.
- 顺手加固: 分隔符改成长串, 正文里即使出现独立 `EOF` 行也不会误触发提前截断; 读取前自动补末尾换行.
