# v0.4.5-preview.8111652 Release Notes

> 🔭 这是 **预览版**（preview）：给加入预览计划的用户提前体验新功能，测试稳定后转为正式版。
> 想先体验可到 设置 → 关于 → 勾选「加入预览计划」；随时可退出。
>
> 本版本是 v0.4.5-preview.8111246 的增量修复。

## 本次修复 🔧

- **修复刷新页面时底栏闪烁**：已定位闪烁根因——底栏「数据库状态」每次页面加载都会从
  「检测中…」异步刷新为「正常」，文字替换一闪而过。现改为**服务端直接渲染最终状态**，
  数据库健康结果随页面一起加载，不再有「检测中→正常」的中间替换，刷新/切页不再闪烁。
  （数据库健康检测结果带 60 秒缓存，不影响性能；设置页仍显示实时结果。）
- **修复「稍后」后再次检查更新失效**：之前点「检查更新」发现新版本 → 弹窗点「稍后」后，
  再次点「检查更新」没反应，必须刷新页面才恢复。现已修复：「稍后」关闭弹窗后即复位状态，
  可随时再次检查并重新弹出。

## 底栏与更新体验（8111246 引入）

- 底栏顺序重排：**Workbench → 署名 → 数据库状态 → 更新托盘**。
- 更新托盘改为内联样式控制显隐，彻底修复无更新时托盘常驻显示。
- 设置页移除独立下载进度条，下载进度统一由全局弹窗 + 底部状态栏托盘展示。
- 更新弹窗可最小化到状态栏（实时进度）、断网 30 秒自动停止并提示重试、
  取消后即可直接再查、下载中提示勿关闭软件。
