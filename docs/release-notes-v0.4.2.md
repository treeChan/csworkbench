# v0.4.2 Release Notes

## 新功能：项目思维导图 🧠

每个项目现在都自带一张画布，可以把研究方向、思路、问题点随手画成一张图，再也不只是线性列表。

入口：左侧栏「🧠 思维导图」→ 选项目 → 进编辑器。

### 节点

- **7 种形状**：矩形 / 圆角矩形 / 椭圆 / 菱形 / 六边形 / 箭头 / 文本框
- **3 色便签**：黄色 / 粉色 / 蓝色 —— 适合临时标注和提醒
- **6 种字体**：默认 / 黑体 / 宋体 / Times New Roman / 楷体 / 等宽
- **字号缩放**：`Ctrl -` / `Ctrl 0` / `Ctrl =` 调整
- **内联编辑**：双击节点直接改文字，支持多行
- **拖拽移动**：画布上随意摆，自动保存位置
- **子节点 / 嵌套**：节点可挂父子层级（用 parent_id 表示）
- **z-index 置顶置底**：多层节点叠在一起时调整显示顺序
- **自动 + 手动双轨**：从项目结构（大目标 / 实验）自动生成的「自动节点」不会误删，
  手动添加的节点可以自由编辑删除

### 连线

- **手动连线**：点工具栏「🔗 连线」再点两个节点即可连；或直接从节点边缘的锚点拖出
- **箭头方向**：每条线可独立切换有/无箭头
- **自动树**：项目里的目标 / 实验会自动以连线呈现父子关系，零手工

### 编辑操作

- **撤销 / 前进**：`Ctrl Z` / `Ctrl Shift Z`（或 `Ctrl Y`），最多 50 步
- **复制 / 粘贴**：`Ctrl C` / `Ctrl V` —— 粘贴到鼠标落点
- **全选**：`Ctrl A`
- **删除**：`Delete` 或 `Backspace`
- **方向键微调**：选中节点后方向键移动，`Shift` 加大步长
- **右键菜单**：选中后右键弹出更多操作
- **连出后自动命名 / 选中文本编辑**：双击进入编辑态，`Enter` 提交，`Esc` 取消

### 同步与持久化

- **自动同步**：拖动 / 编辑后实时把节点位置、标签、连线、样式写回 SQLite
- **手动同步**：右上角「🔄 同步」按钮兜底（比如改完项目结构想立刻拉新自动节点时）
- **保存状态指示**：右上角显示 ● 已保存 / ● 未保存

### 数据模型

新增三张表：

```
Mindmap (项目一对一, UNIQUE)
  └── MindmapNode (节点: x/y/w/h, shape_type, label, kind=auto/manual,
                  parent_id, z_index, font_size, font_family, color,
                  sticky_color, has_arrow)
        └── MindmapEdge (连线: source_id, target_id, kind=auto/manual, has_arrow)
```

删除项目时 `ON DELETE CASCADE` 自动清掉对应导图，不留垃圾。
