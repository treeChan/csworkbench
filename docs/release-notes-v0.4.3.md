# v0.4.3 Release Notes

## 思维导图编辑器升级 🧠

### 多选 + 框选

- **Shift + 点击**：切换单个节点的选中状态
- **空白处拖拽**：拉出虚线矩形，框选所有相交节点（手动 + 自动都可框选，类 Figma / Excalidraw 交互）
- **Ctrl + A**：一键全选所有节点
- **Esc**：清空选中
- **多选后批量操作**：
  - 删除（自动节点会被跳过并提示数量）
  - 字号缩放（Ctrl + / Ctrl - / Ctrl 0）
  - 字体切换（所有选中节点一并改）
  - 方向键微调位置（Shift 加大步长）
  - 拖拽（一起移动）
  - 自动节点在多选拖拽时自动跳过（它的位置由项目数据决定）
- **多选时锚点不再乱飞**：锚点（节点四周 4 个紫色圆点）只在「连线模式」下显示，多选时不再出现一堆散落的点
- **多选删除会进单个撤销栈**：一次撤销可恢复全部

### 锚点位置 Bug 修复

- 之前椭圆 / 菱形 / 六边形 / 箭头节点的 4 个锚点（连线用的紫色圆点）会显示在错误的位置 —— 因为代码用 `<rect>` 的 width/height 取尺寸，但这些形状不是 `<rect>`
- 现在节点 `<g>` 上加了 `data-w` `data-h`，锚点读取真实尺寸，与节点形状精确对齐

### 箭头 + 线条风格统一

- **箭头颜色**：之前是黑色（`<marker>` 里 `fill="currentColor"` 在 `<defs>` 里没有 currentColor 可继承），现在统一为紫色（`var(--c-primary)`），与手动连线同色
- **自动连线色调**：从灰色（`var(--c-border)`）改成浅紫（`var(--c-primary-light)` + opacity），保留「细 + 半透明」的弱化层级，但色调与手动连线一致

### 字体选择改下拉框

- 工具栏原来 6 个字体按钮（默认/黑体/宋体/Times New Roman/楷体/等宽），现在改成 `<select>` 下拉框
- 多选时也能批量应用
- 占空间小，留出更多位置给节点画布

### 导出 PNG

- 工具栏新增「📷 导出 PNG」按钮
- 导出内容：所有节点 + 所有连线（手动 + 自动），不含背景网格
- 2x 高清分辨率（适合贴文档 / 演示文稿）
- 文件名：`mindmap-{项目ID}-{时间戳}.png`
- 实现：克隆 SVG → 移除网格/锚点/选中态 → 内联 CSS → 按所有节点 bbox 计算 viewBox → Canvas 渲染 → 下载
- 白底（PNG 透明背景通常不好看）
