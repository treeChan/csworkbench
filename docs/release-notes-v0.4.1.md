# csworkbench v0.4.1 — 首个公开版本

> 这是本项目**首次对外公开发布**的版本。功能已可用，但仍在持续打磨中，
> 欢迎试用并反馈，后续版本会不断完善。
> 安装前建议先备份数据（设置页 → 下载完整备份）。

## 这是什么

Workbench · 研究驾驶舱 —— 一个**完全跑在自己电脑上**的科研管理工具，用来同时跟踪多个
研究方向的目标、实验和结论。

- **数据全在本机**：所有记录保存在你电脑的一个 SQLite 文件里，不上传任何服务器，无需注册账号，离线可用。
- **结构清晰**：项目 → 大目标 → 实验 三级组织，附实验设计 / 结果 / 指标 / 笔记 / 周复盘。
- **开箱即用**：桌面 App 已打包 Python 运行时，Windows / macOS / Linux 双击即用，无需装环境。

## 更新方式（双轨）

- **在线更新**：设置页「关于 → 检查更新」，弹窗展示更新日志并选择是否下载安装。已发布，当前版本即可检测到更新。
- **安装包覆盖升级**：在已装旧版上运行新安装包，自动识别已装版本并**继承原安装位置**，
  直接覆盖更新，不弹「先卸载再安装」，配置与数据原样保留。

## 主要功能

- **战情室**：所有项目一屏看完，卡片显示进度、阶段、待传结果数。
- **项目 / 大目标 / 实验**：目标分解 + 实验设计与结果记录，指标纯记录、图片 / 权重可上传。
- **决策日志 / 周复盘**：跨项目待办与每周小结。
- **搜索**：快速搜索（标题）+ 全文搜索（设计 / 笔记 / 正文）。
- **完整备份 / 恢复**：一键导出 zip 跨电脑迁移，恢复前自动备份、失败自动回滚。
- **主题**：跟随系统 / 亮色 / 暗色。
- **数据安全**：状态栏实时检测数据库健康（integrity_check），改动路径自动迁移并校验。

## 已知限制

- **macOS 未签名**：首次运行需右键 → 打开，或终端执行 `xattr -cr "/Applications/csworkbench.app"`
  放行（Apple 开发者证书 $99/年，后续版本考虑）。
- **Windows 未签名**：SmartScreen 可能提示「未知发布者」，点「仍要运行」即可；代码签名证书后续考虑。

## 兼容性

- 桌面版：Windows 10/11、macOS 12+、主流 Linux（AppImage / deb / rpm）。
- 另提供浏览器版（`run.sh` / `run.bat`），与桌面版共用同一套功能。
