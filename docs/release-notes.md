# v0.4.5-preview.8111246 Release Notes

> 🔭 这是 **预览版**（preview）：给加入预览计划的用户提前体验新功能，测试稳定后转为正式版。
> 想先体验可到 设置 → 关于 → 勾选「加入预览计划」；随时可退出。
>
> 本版本是 v0.4.5-preview.8111008 的增量修复。

## 本次修复 🔧

- **彻底修复底栏更新托盘闪烁**：上一版本在无下载任务时底栏托盘已能隐藏，但切换页面时
  仍会快速闪一下。本版改为内联样式控制显隐，任何页面加载时序下都不会闪现——
  只有真正下载更新（含最小化后）才会出现。
- **设置页移除独立下载进度条**：下载进度统一由全局弹窗 + 底部状态栏托盘展示，
  设置页不再重复显示进度条，信息不再分散。
- **底栏顺序重排**：从左到右依次为 **Workbench → 署名 → 数据库状态 → 更新托盘**，
  更新托盘位于最右侧（键盘快捷键提示左侧）。

## 更新体验优化 ⚙️（8102246 引入）

- 修复「取消更新后需跳页才正常」：取消后即可直接再查，并弹「更新已取消」提示。
- 断网不再无限等待：下载时断网（连续 30 秒无进展）自动停止并提示「网络连接已中断」，
  检查网络后点「重试」继续。
- 更新弹窗可最小化：下载中可收起弹窗到底部状态栏，状态栏实时显示进度
  （百分比 / 速度 / 剩余时间），点击状态栏恢复弹窗；下载完成自动弹出提示。
- 下载中提示「下载时请不要关闭软件，否则更新会中断」。

## 思维导图新能力 🗂️

- **容器节点**：圆角虚线框 + 半透明紫底，拖动普通节点落入容器自动绑定，子节点跟随。
- **笔记 Markdown 渲染**：实验详情 / 结果页笔记支持 Markdown 与纯文本切换。
- **搜索高亮**：全局搜索命中关键词展示上下文并高亮（紫色 <mark>）。
- **连线重做**：纯锚点拖拽（Figma 风格）、修复上下连边失败、自动清理孤儿连线、
  节点填色/字色自定义、PNG 导出修复。
