# v0.4.1 Release Notes

## 修复与优化

### 1. 在线更新（设置页「检查更新」）
- **修复**「检查更新失败：Command not allowed by ACL」——桌面端权限配置补上了更新命令。
- 检测到新版本时弹窗**展示更新日志（release notes）**，并让用户选择是否下载安装；
  更新日志来自 GitHub Release 说明，过长会自动截断。

### 2. 安装包覆盖升级（Windows）
- 升级时**自动识别已装旧版本并继承原安装位置**，不再弹出「选择安装位置」页面；
  全新安装才让选目录。
- 安装进度区明确显示**「正在更新 csworkbench」**，而不是静默覆盖，让用户清楚这是升级。
- 保留原有行为：不弹「先卸载再安装」、appdata 里的配置与数据原样保留。

### 3. 设置页「关于」表格
- 「版本」一行垂直居中对齐（之前因按钮把行撑高而偏上）。

## 其他

- 版本号升级至 **v0.4.1**。
- macOS 未签名版本首次运行仍需右键 → 打开，或终端执行 `xattr -cr` 放行（见 README）。
