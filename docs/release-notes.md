## 桌面端冷启动优化 🚀

桌面应用（macOS / Windows / Linux）首次打开到首屏可用的耗时从约 **25 秒降到 12–13 秒**（macOS Apple Silicon 实测），约 **50% 提升**。

- **明确排除大型三方包**：`tkinter`、`unittest`、`numpy`、`pandas`、`matplotlib` — 这些从未在服务里用到，但 PyInstaller 默认会带上它们的导入路径。
- **裁剪 SQLAlchemy 方言**：只用 SQLite，运行时显式排除 `mssql / oracle / postgresql / mysql / sybase / informix / maxdb / firebird` 与 `sqlalchemy.testing` 全部分支，导入链砍掉一大截。
- **裁剪 Pydantic 子模块**：排除 `pydantic.deprecated`、`pydantic.experimental`（只用 `test` 主体），不影响运行时校验。
- **Markdown 不走 `collect_all`**：只调用基础 `markdown()` API，不再把 `markdown.extensions.*` 全部打包进镜像。
- PyInstaller `.spec` 文件已就位（`desktop/sidecar/workbench-server.spec`），后续升级可直接复用。

> 优化前后实测在同一台 M-series MacBook 上完成（系统空闲 + 冷启动）；详细对比与 `excludes` 完整列表见发布 commit。

## 实验图表（Plotly）📈

实验详情页加入 **Plotly 折线图区**，让数值类数据点的变化一眼可读。

- **Plotly 图表区**：每个实验可挂载多组 `key: value` 数据点，自动按 key 分组渲染为多线折线图，鼠标悬停显示精确数值。
- **批量粘贴**：粘贴 TSV / CSV 多行文本时，自动按行拆分为多条数据点（自动识别 `时间 / 条件 / 值` 等常见列名），不再逐条手动录入。
- **图表逐条勾选**：每个数据点旁边加 checkbox，勾选要展示的子集，不勾的不进图，方便对比「指定条件下」的趋势。
- **删除跳转**：删除某条数据点后页面回到图表区，不会再把用户甩到空白列表；删除前有二次确认。

## 思维导图编辑全面修复 🧠

v0.4.5 之后的预览版累计修了三批思维导图相关 bug，本正式版一并发布。

### 编辑功能完全失效的根因（最严重）

- **症状**：从 `08241339` 起导图页右上角编辑按钮点了没反应，整张画布变成只读。
- **根因**：模板里 `syncDiff` 字段用了 Jinja 的 `| tojson`，但项目自定义的 `tojson` filter 返回的是普通 `str` 而非 `Markup`，autoescape 把 `"` 转义成 `&#34;`，而 `<script>` 标签是 raw text 不解码实体 → `MM_BOOT` 对象整段 JS 语法错误 → 编辑器没起来。
- **修复**：所有 `| tojson` 改为 `| tojson | safe`（参考 `workbench-gotchas.md` 第 #18 项）。HTML 头部加 `Cache-Control: no-cache`，避免浏览器拿到旧 bundle。

### 布局与交互（`08241522` / `8241708`）

- **左栏宽度不再漂移**：进入导图页后左侧导航保持全局一致的 84px，不再因内容伸缩。
- **工具栏文字按钮不再截断**：「入容器 / 移出 / 导出 PNG」等带文字按钮此前被固定宽度压扁，出现文字重叠、截断、丢失。现在按钮按内容自适应宽度，纯图标按钮保持等宽。
- **全局功能恢复**：此前导图页把全局脚本整块清空，导致主题切换、`Ctrl+K` / `Ctrl+N` 快捷键、快速创建、数据库健康检测、更新弹窗等全部失效 — 现已全部恢复。
- **画布高度修正**：画布容器改为填满主区网格，底部不再被裁掉。
- **`Ctrl+K` 不再抢焦点**：导图页搜索框隐藏时不聚焦它，画布快捷键（`Del` / `Ctrl+Z` / `Ctrl+Shift+Z`）正常工作。
- **拖动 / 字体 / 箭头 / 按钮改名** 等细节（`08241522`）：选中节点拖动顺畅，字体大小调整不丢字，箭头方向正确，「删除子节点」按钮统一改名。

## 项目页 UX 改进 📋

项目详情页两个用户反馈最多的痛点都修了。

### 「当前研究阶段」加数据佐证条（方案 A）

- 项目首页显示当前所处的研究阶段（立项 / 进行中 / 复盘 / 归档），下方紧跟一行数据佐证：当前目标数、已结束实验数、最近 7 天活动数、最近一次更新距今天数。
- 阶段是手动标签，标签旁给出依据数字，避免「看着像在推进实际没数据」的错觉。

### 编辑与删除的边界更清晰

- **项目编辑改走更新路由**：之前表单 `action` 在某些分支下走的是「新建」路由，导致用户改了一个字段、保存后变成多出一条新项目。已按模式路由（`mode=create` / `mode=edit`），表单 `action` 与提交按钮文案对应。
- **删除按钮收敛到侧滑 / 菜单**：项目详情页右上角不再悬着大红色「删除」按钮，避免误触。删除入口收敛到侧滑菜单 + 二级确认（输入项目名确认），与实验/目标页删除保持一致体验。

## 文件与成果栏目重构（C1–C4）📂

围绕「文件与成果」栏目，按用户反馈分四步重构（v0.4.5 之后累计完成）：

- **C1 — 创建实验默认选中当前目标**：新建实验表单的目标下拉默认选中当前项目「进行中」目标（URL `?goal_id=`），不用每次手动选。
- **C2 — 文件树 + 缩略图网格 + 灯箱**：`build_artifact_tree` 在 Python 端构建好嵌套结构，Jinja 只负责渲染；图片类成果在网格视图下点击进入灯箱（全屏 + 左右翻页 + 缩放）。
- **C3 — 项目级自定义类别 + 类别下子目录**：`Project.categories_json` 字段存项目自定义类别（如「数据」「模型」「论文截图」），每个类别下可有子目录。
- **C4 — 拖拽改子目录 + 子目录改名**：拖拽成果到目标子目录即时生效；子目录支持重命名，API 端做重名 / 与现有 folder 重合的校验。

## 构建流程加固 🛠️

- 修复预览版 CI 在「读取 release notes」步骤偶发失败的问题：`docs/release-notes.md` 末尾缺换行 → heredoc 的 `EOF` 分隔符与内容粘成一行 → 解析报 `Matching delimiter not found 'EOF'`。已加固：分隔符改成长串、读取前自动补末尾换行。
- 顺手记入 `workbench-gotchas.md`：**版本号格式坑**（`docs/versioning.md`）— 8 月预览版必须用 `824XXXX`（**月去前导零**），`0824XXXX` 带前导零会被 Cargo 拒绝（`invalid leading zero in pre-release identifier`）；上游 `08241339` / `08241522` 两个版本号都违反此规则、从未构建成功过。
